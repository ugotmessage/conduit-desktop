# Retired Appwrite experiment

The prior private-Appwrite plan override is no longer part of this branch. The project now uses an **opt-in signed-out Local Mode** with synced vault files instead.

See [Local file sync](LOCAL_FILE_SYNC.md) for Synology Drive, iCloud Drive, OneDrive and Dropbox instructions, device-limit behavior, tests and caveats.

No website, database, Appwrite stack or subscription service needs to be deployed for this mode.
